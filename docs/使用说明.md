# 智家伴蓝牙串口助手 — 使用说明(E104-BT53 调试上位机 · C# / WinForms 现代深色版)

配套《E104-BT53 产品规格书 CN v1.6》第六章全部 **33 组 AT 指令**的 Windows 调试上位机。
**原生单文件 exe**(仅依赖系统自带 .NET Framework 4.8,无需安装任何运行库);串口/协议层已在真机
COM3 全量验证(19 项自检全部通过,含交互式两步指令)。

## 一、运行与构建

| 操作 | 方法 |
|---|---|
| 直接运行 | 双击 `智家伴蓝牙串口助手.exe` |
| 重新编译 | 双击 `一键编译.bat`(用系统自带 csc,无需 .NET SDK/NuGet,任何 Win10/11 可用) |
| 在 VS 里开发 | 用 Visual Studio 打开 `.cs` 源文件即可(经典 .NET Framework 4.8 / WinForms 项目;注意源码为 **C#5 语法**,兼容旧编译器) |
| 协议自检 | 运行 `TestProto.exe`(模块接 COM3 时,自动验证 19 项) |

## 四、实时串口显示(串口助手式,参考 SSCOM/XCOM)

| 功能 | 说明 |
|---|---|

| **手动发送(串口助手式)** | 日志区下方输入行:输入内容 **[发送]** 或按 **Enter** 即发;↑↓ 翻 50 条历史 |

| 日志长度保护 | 日志台 3500 行 自动减半,不卡界面 |

## 五、发送区(AT 终端页,串口助手增强)

| 功能 | 说明 |
|---|---|
| **ASCII / HEX 发送** | 格式下拉切换;HEX 严格校验(偶数个十六进制字符),按原始字节写出 |
| **加 `\r\n` 可选** | 勾选=标准 AT 指令(带应答等待);**不勾选=透传原始数据**(配置模式外直发) |
| **定时重发** | 勾选后按设定间隔(ms,下限 100)循环发送当前内容;断开自动停止;RESET/RESTORE 会先停定时 |
| **宏指令** | 下拉预置 16 条常用指令(含扫描/观察者/复位),[发送宏] 直接发、[仅填入] 填到输入框 |
| 历史记录 | ↑↓ 键翻 50 条历史;Enter 直接发送 |
| 快捷按钮 | AT / 角色 / 连接列表 / 看门狗 / 版本 / 重连列表 一键查询 |

### 注意事项
- 两帧指令毫秒级连发会粘连(实测 `AT+ROLE?×2 → +ERR=1`),工具已做**应答等待 + 20ms 最小帧间隔**双保险,连点安全。
- 定时重发会持续占线,请确保模块当前处于接收配置指令的状态(唤醒模式)。

## 六、核心机制(全部源于真机实测)

1. **应答等待 + 20ms 最小帧间隔**(手册 5.7):连点也不会粘连;连接后自动 AT 握手 → 单链读取角色/名称/MAC/版本。
2. **一键读取**:按当前角色只发受支持的查询,33 组参数当前值全量回填"总览"页;可导出 JSON 快照。
3. **角色感知**:从角色时"主机连接"页自动置灰(可勾选"强制允许"实测 +ERR=4)。
4. **交互式两步指令**:ADV_EXT / SEND 启动后,状态栏提示待输入字节数,[发送数据] 按钮点亮,自动校验/截断长度。
5. **扫描表格**:实时去重列表(序号/MAC/RSSI/名称),**双击行即发起连接**;RSSI/名称列即模块原样输出。
6. **观察者**:广播流独立窗口,自动滚动可暂停;扩展广播观察者(mode 2)会提示先设 SCAN_PHY=1。
7. **危险操作分级确认**:RESET / RESTORE(两次确认)/ BAUD / SLEEP 关串口(附 CTS 唤醒说明)/ 断开全部 / 清空重连列表。
8. **RTS 唤醒脉冲**:Beacon 角色或 `AT+SLEEP=0,x` 关串口后,一键发出 CTS 上升沿 ×3。
9. **错误码即时翻译**:+ERR=1/2/3/4 在状态栏直译中文含义,+ERR=4 时提示角色不符的处置方法。

## 七、与手册差异提示(已内置到 UI 提示)

- `AT+VERSION?` 实测 `+VERSION=7413-1-16`(手册示例 `+OK=` 前缀不符)
- `AT+TRM_HANDLE?` 无连接返回 `255`(即无句柄)
- `AT+DEV_DEL` 删除不存在的 MAC 实测 `+ERR=2`(手册写错误码 3)
- 手册 6.3.14 示例 MAC 仅 5 字节会判 `+ERR=2`,本工具强制 6 字节校验
- `AT+AUTH` 仅手机 APP 通道有效,串口发送回 `+ERR=4` 属正常(界面已注明)
- A1 版本不支持 LE_CODED / SCAN_PHY / OTA,最大发射功率 0dBm

## 八、角色支持矩阵

| 角色 | 可用页/指令 |
|---|---|
| 0 从(默认) | 除"主机连接"页外全部;SCAN/CONNECT/OBSERVER/TRM_HANDLE → +ERR=4 |
| 1 单主 | "主机连接"页全部;ADVDATA/LE_CODED/ADV_EXT 设置 → +ERR=4 |
| 2 主从一体 | 全部指令可用 |
| 3 Beacon | 广播/Beacon 参数;上电串口关闭,需先按 ⚡RTS唤醒 |
